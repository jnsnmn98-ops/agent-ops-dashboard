# 영상 에이전트 팀 관제실

Claude Code로 만든 광고 영상 기획 에이전트 팀(총괄 디렉터 1명 + 전문 에이전트 11명)이 실제로 일한 기록을 재생하는 대시보드입니다.

**웹에서 보기:** https://jnsnmn98-ops.github.io/agent-ops-dashboard/

## 화면

| 탭 | 내용 |
|---|---|
| Workflows | 디렉터를 중심으로 한 연결 그래프. 기록 순서대로 지시와 결과가 선을 따라 오가고, 실행 중인 에이전트·디렉터 로그·만든 파일이 함께 갱신됩니다. |
| Traces | 에이전트 실행을 보라(작업)·청록(검토·검수) 간트 차트로 보여 줍니다. 막대를 누르면 시간·토큰·도구 호출·만든 파일이 나옵니다. |
| Usage | 사람 작업 대비 단축(가정값 조정), 캐시 재사용률, 동시 실행 비율, 에이전트별 토큰, API 정가 환산 비용. |
| Protocol | 요청 하나가 지나가는 9단계, 고객 리뷰에서 장면까지 이어지는 근거 사슬, 교차 검토 짝, 사용자 결정 지점, 에이전트별 도구 제한. |

## 데이터

- 2026-11-11에 진행한 프로젝트 2건, 에이전트 실행 23회의 Claude Code 세션 기록(시작·종료 시각, 토큰 사용량, 만든 파일)
- 비용은 Claude Opus 5.5 API 정가로 환산한 추정치이며 실제 결제 금액과 다를 수 있습니다.
- "사람이 할 때" 시간은 측정값이 아니라 화면에서 조정하는 가정값입니다.
- P1의 「놓고」는 가칭인 가상 브랜드입니다. P2는 실존 브랜드 노도르에 제안하는 개인 시안이며 노도르의 공식 광고가 아닙니다.

## 기술

빌드 없는 단일 HTML 파일입니다. Tailwind CSS(CDN), Vanilla JS, 인라인 SVG를 씁니다. `index.html`을 브라우저로 열거나 정적 호스팅에 그대로 올리면 됩니다.
