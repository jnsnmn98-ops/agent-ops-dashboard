    Guardrails

    기술적으로 막혀 있는 것

    지침은 모델에게 주는 지시입니다. 실제로 강제되는 것은 에이전트 파일의 도구 목록뿐입니다.

    Read에는 Glob·Grep이 함께 들어 있습니다. 표현 검수는 쓰기 도구가 없어서 결과를 디렉터가 저장합니다.

    데이터: Claude Code 세션 기록(.jsonl)의 타임스탬프와 토큰 사용량, 프로젝트 폴더의 산출물. 2026-11-11 진행, 2026-11-12 집계. 시각은 한국 시간(KST)입니다.

    비용은 Claude Opus 5.5 API 정가(100만 토큰당 입력 $4 · 출력 $20 · 캐시 읽기 $0.20 · 캐시 쓰기 $5(5분)/$8(1시간))로 환산한 추정치이며, 실제 결제 금액(구독 요금)과 다를 수 있습니다. "사람이 할 때" 시간은 측정값이 아니라 직접 조정하는 가정값입니다.

    P2는 실존 브랜드 노도르에 제안하는 개인 시안이며, 노도르의 공식 광고가 아닙니다. P1의 「놓고」는 가칭인 가상 브랜드입니다.
